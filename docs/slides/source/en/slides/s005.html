How to read the code slides

// a comment explains the line below
#define LOOP_TIME_US  4000

void loop() {
  mpuReadRaw();  // read sensor
}

Grey = a comment. The compiler ignores it; it is for humans.

Orange = a C++ keyword such as void, if, float.

White = the code itself. Names come from the real file.

Code is shortened with “…” when a part is not needed for the idea. The footer says where it lives.

Every code slide follows this colour key. The firmware is one Arduino sketch, Esp32_drone.ino, about 2,600 lines. We never show all of it at once: each slide shows only the few lines behind one idea, with the function name in the footer so you can find it.
