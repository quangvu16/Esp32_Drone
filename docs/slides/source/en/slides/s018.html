How it flies

One control loop, 250 times every second

The same four steps, 250 times every second.

Sense: read gyro and accelerometer over SPI.

Estimate: work out the tilt angles.

Decide: the PID compares want with have.

Act: the mixer sets four motor duties — then wait until 4 ms have passed.

Example

Gyro says 6 °/s roll → angle 2.1° → PID wants 0 → left motors +8, right −8 → wait.
