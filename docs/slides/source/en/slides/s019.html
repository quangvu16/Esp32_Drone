How it flies

Why 250 times a second?

4 ms

per loop (LOOP_TIME_US 4000). Short enough to catch a tilt before it grows.

250 Hz

the sensor sample rate is set to match: 1 kHz ÷ (1 + 3).

≈ 0.5°

an example drift between two loops — small, so each correction is small.

Rule of thumb: the loop must run much faster than the drone can tip over.

How it flies · 19 · Source: Esp32_drone.ino #define LOOP_TIME_US, mpuInit() SMPLRT_DIV

Why not faster? The sensor is set to 250 Hz samples, the radios and logging need time, and the brushed motors cannot respond faster anyway. Why not slower? Corrections would come late and would have to be bigger, which makes the drone wobble. The 0.5 degree figure is an illustration.
