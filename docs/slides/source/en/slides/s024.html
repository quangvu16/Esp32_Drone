MPU6500: the motion sensor

One small chip with two sensors inside, each measuring three axes.

Gyroscope

How fast the drone is rotating, in degrees per second. Range set to ±500 °/s.

Accelerometer

The push it feels, including gravity. Range set to ±8 g.

SPI connection

The ESP32 reads 14 bytes in one burst every loop.

Hardware · 24 · Source: TDK InvenSense MPU-6500 datasheet; Esp32_drone.ino mpuInit()

The firmware checks the WHO_AM_I register at start-up: 0x70 means MPU6500, 0x71 means MPU9250. If neither answers, setup() stops and prints a wiring hint, because flying without the sensor is impossible.
