Gyro and accelerometer: each fixes the other

Each sensor is wrong in a different way.

Gyroscope: fast and smooth, but a small bias adds up — the angle drifts.

Accelerometer: knows where “down” is and never drifts, but vibration makes it noisy.

Section 5 combines them so each covers the other's weakness.

Example

Gyro = a stopwatch (precise, drifts). Accelerometer = the sun (always right, hard to read on a cloudy day).
