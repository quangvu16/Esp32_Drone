8520 coreless brushed motors

The name is the size: 8.5 mm wide, 20 mm long.

Brushed

Spin faster with more average voltage. No ESC needed.

Coreless

Light rotor, so speed changes quickly — good for control.

Driven by duty

The firmware sets how much of each cycle the MOSFET is on.

Hardware · 29 · Source: Esp32_drone.ino Motor PWM section comment

Big drones use brushless motors with an ESC that understands servo pulses (1000 to 2000 µs). This drone keeps that 1000–2000 number inside the code for familiarity, but converts it to a PWM duty for the MOSFET. Section 7 shows usToDuty().
