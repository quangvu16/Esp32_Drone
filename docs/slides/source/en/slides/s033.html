Reading and smoothing the battery

uint32_t mv = analogReadMilliVolts(PIN_VBAT);
float sample = (mv / 1000.0f) * VBAT_DIVIDER;
if (vbat <= 0.0f) vbat = sample;        // first read
else vbat += VBAT_FILTER_ALPHA * (sample - vbat);

analogReadMilliVolts uses the chip's factory calibration.

Alpha 0.02: each loop moves 2% toward the new reading — about a 0.2 s time constant.

Why smooth? One reading is noisy and dips with every throttle punch.

Example

Old value 3.90 V, one noisy sample 3.60 V → new value 3.90 + 0.02 × (−0.30) = 3.894 V. One bad reading barely moves it.

This is a first-order low-pass filter, also called an exponential moving average. Example: the old value is 3.90 V and a noisy sample reads 3.60 V. The new value is 3.90 + 0.02 × (−0.30) = 3.894 V. One bad sample barely moves it, but a real drop shows up within a fraction of a second.
