What is NOT on the board — and why it matters

No barometer

Cannot measure height. Hold keeps a thrust level, not an altitude.

No compass

Heading comes from the gyro only, so it drifts slowly.

No GPS

Cannot know its position. Follow uses the phone's GPS and dead reckoning.

No rangefinder

Cannot see the ground. Landing is a timed thrust ramp.

Hardware · 38 · Source: Esp32_drone.ino FLIGHT MODES and NAVIGATION section comments

This is the most important design constraint in the firmware. The code comments say it plainly, and the app UI is honest about it too: it never draws a fake altitude. When you read the flight-mode and navigation code later, remember these four missing sensors.
