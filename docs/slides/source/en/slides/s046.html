loop() in twelve lines

sbusPoll();  linkPoll();            // 1. receive
// 2. decide who is in control, failsafe
if (!rx_ok && armed) { armed = false; motorStop(); }
armUpdate(now, use_crtp);           // 3. arm / disarm
mpuReadRaw();  attitudeUpdate();    // 4. sense
navUpdate(...);                     // 5. dead reckoning
flightSetpoints(now, use_crtp, sbus_ok);  // 6. want
roll_setpoint = sp_roll_rate - roll_level_adjust;
pidCompute();                       // 7. decide
motorMix(sp_throttle_us);           // 8. mix
motorWrite(motor_rf, motor_rr, motor_lr, motor_lf);
batteryUpdate(); logUpdate(); telemetry(now);
while (micros() - loop_timer < LOOP_TIME_US) { }

Shortened — the real loop has comments and checks between these lines.

Order matters: safety checks come before sensing and control, so a lost link stops the motors in the same loop.
