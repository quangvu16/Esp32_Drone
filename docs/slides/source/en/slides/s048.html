Hard 250 Hz pacing

// ---- hard 250 Hz pacing ----
while (micros() - loop_timer < LOOP_TIME_US) { /* spin */ }
loop_timer = micros();

Busy-wait: the CPU spins until exactly 4 ms have passed since the last loop.

Why exact timing? The gyro is integrated with a fixed dt of 0.004 s. A loop of the wrong length gives the wrong angle.

Wrap-safe: unsigned subtraction still works when micros() overflows after ~71 minutes.

Example

The work takes 1.3 ms this loop → the spin lasts 2.7 ms. Next loop the work takes 2.1 ms → the spin lasts 1.9 ms. The period stays 4 ms.

Why not use delay()? delay() waits a fixed time no matter how long the loop work took, so the period would change with the workload. The busy-wait absorbs the variable work time. The cost: if the work ever takes longer than 4 ms, the loop runs late and dt is wrong for that loop.
