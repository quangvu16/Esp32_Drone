Architecture

Four design principles you will see everywhere

Safety first in the loop

Failsafe and arming run before control, every loop.

Honest about limits

No barometer → no fake altitude. Comments say so.

Commands are idempotent

The app resends every 500 ms, so applying a command twice must be safe.

Tests pin fragile lines

run.sh fails if a tested formula changes in the sketch.

These four ideas explain most of the code you will read. When a piece of code looks strange, ask which of the four it is serving. For example, the TAKEOFF handler ignores a repeated TAKEOFF while climbing: that is principle 3.
