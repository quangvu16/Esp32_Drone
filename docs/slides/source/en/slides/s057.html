Talking to a register over SPI

uint8_t mpuRead(uint8_t reg) {
  mpuSelect();                     // CS low
  SPI.transfer(reg | 0x80);        // bit7 = 1 -> read
  uint8_t v = SPI.transfer(0x00);  // clock the answer out
  mpuDeselect();                   // CS high
  return v;
}
// write: reg & 0x7F (bit7 = 0), then the value

First byte = register address. Its top bit says read (1) or write (0).

SPI is a swap: to receive a byte you must send one, so we send 0x00.

CS low starts the conversation; CS high ends it.

Example

Read WHO_AM_I (register 0x75): send 0xF5 (0x75 | 0x80), then 0x00, and the sensor answers 0x70 for an MPU6500.
