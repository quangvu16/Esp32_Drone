One burst read: 14 bytes, all axes

void mpuReadRaw() {
  uint8_t buf[14];
  mpuReadBurst(MPU_REG_ACCEL_XOUT, buf, 14);
  raw_ax = (int16_t)(buf[0]  << 8 | buf[1]);
  raw_ay = (int16_t)(buf[2]  << 8 | buf[3]);
  raw_az = (int16_t)(buf[4]  << 8 | buf[5]);
  /* buf[6..7] = temperature (skip) */
  raw_gx = (int16_t)(buf[8]  << 8 | buf[9]);
  raw_gy = (int16_t)(buf[10] << 8 | buf[11]);
  raw_gz = (int16_t)(buf[12] << 8 | buf[13]);
}

Registers 0x3B…0x48 sit next to each other, so one read gets everything.

Why one burst? All six values come from the same instant, and it is fast.

The order in the register map is accelerometer X, Y, Z, temperature, gyro X, Y, Z. Each value is two bytes, high byte first. The temperature is read but skipped, because the firmware does not use it.
