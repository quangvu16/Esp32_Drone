Two bytes make one signed number

Each value is 16 bits, sent high byte first. The cast to int16_t makes it signed.

Positive

0x01, 0x2C → 0x012C = 300

Negative

0xFF, 0x38 → 0xFF38 = −200 (two's complement)

Range

−32768 to +32767 for every axis

Example

buf[8] = 0xFF, buf[9] = 0x38 → raw_gx = −200 → −200 ÷ 65.5 = −3.05 °/s.

Motion sensor · 60 · Source: Esp32_drone.ino mpuReadRaw()

Why the (int16_t) cast? Without it, the shifted value is an int, and 0xFF38 would be read as 65336 instead of −200. The cast tells C++ that the top bit is a sign bit. Forgetting this is a classic sensor bug: the drone sees a huge positive rotation whenever it actually rotates slightly negative.
