PID control

D: brake before you overshoot

D reacts to how fast the error is changing. It is a damper.

Code

D = Kd × (error − last error).

Roll and pitch Kd

18 — large, because the change per 4 ms loop is small.

Too much D

Hot motors and a high-pitched buzz: D amplifies sensor noise.

Example

Error goes from 10 to 7 in one loop → change −3 → D = 18 × (−3) = −54, braking the correction before it overshoots.

PID control · 73 · Source: Esp32_drone.ino #define PID_ROLL_KD, PID_YAW_KD

Why no D on yaw (Kd 0)? Yaw changes slowly and its torque is weak, so it rarely overshoots, and D would only add noise. Why is D so sensitive to noise? Noise changes quickly from loop to loop, and D multiplies every quick change by 18.
