err = gyro_roll - roll_setpoint;
pid_i_mem_roll += pid_i_gain_roll * err;
pid_i_mem_roll = constrain(pid_i_mem_roll,
                     -I_TERM_LIMIT, I_TERM_LIMIT);
pid_p_roll = pid_p_gain_roll * err;
pid_i_roll = pid_i_mem_roll;
pid_d_roll = pid_d_gain_roll * (err - pid_last_roll_err);
pid_output_roll = pid_p_roll + pid_i_roll + pid_d_roll;
pid_last_roll_err = err;
pid_output_roll = constrain(pid_output_roll,
                     -PID_LIMIT, PID_LIMIT);

Line by line: compute the error, add to the I memory and clamp it, compute P, copy I, compute D from the change in error, add them, remember this error for next loop, and clamp the output. Notice there is no dt anywhere: the gains already include the fixed 4 ms loop time.
