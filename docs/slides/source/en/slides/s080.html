Self-level in code

float roll_err_deg = angle_roll_deg - sp_roll_deg;
roll_level_adjust = constrain(
    roll_err_deg * LEVEL_SENSITIVITY, -200.0f, 200.0f);
// The level term is SUBTRACTED.
roll_setpoint = sp_roll_rate - roll_level_adjust;

Angle error → times 15 → a rate in °/s, clamped to ±200.

Subtracted: tilted too far one way, ask to rotate the other way.

sp_roll_rate adds the pilot's own rate command (SBUS) on top.

Example

Tilted +5° past the target → adjust = 5 × 15 = 75 → rate setpoint −75 °/s → the drone rotates back.
