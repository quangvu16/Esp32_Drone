From the sticks to setpoints

// SBUS: rate mode, 16 µs dead-band around centre
if (rc[CH_ROLL] > 1508)
  sp_roll_rate = (rc[CH_ROLL] - 1508) / SETPOINT_DIVISOR;
else if (rc[CH_ROLL] < 1492)
  sp_roll_rate = (rc[CH_ROLL] - 1492) / SETPOINT_DIVISOR;
// Phone MANUAL: angles, capped at ±25°
sp_roll_deg = constrain(cmd_roll_deg,
                        -MAX_TILT_DEG, MAX_TILT_DEG);

Dead-band 1492–1508: a stick resting near centre commands nothing.

÷ 3 (SETPOINT_DIVISOR): full stick 2000 → (2000 − 1508) ÷ 3 = 164 °/s.

The phone sends tilt angles; SBUS sends rates.

Why the dead-band? Sticks never rest exactly at 1500, and a tiny offset would make the drone slowly rotate. Why do the phone and SBUS differ? A touch screen is imprecise, so commanding an angle that self-levels is easier; an RC pilot gets rate mode with self-level underneath.
