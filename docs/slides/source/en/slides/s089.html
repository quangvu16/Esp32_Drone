Limits inside the mixer

int16_t t = constrain(throttle, RC_MIN, THROTTLE_MAX);
if (t > THROTTLE_ARM_MAX) {          // above 1050
  ... four mixer lines ...
  motor_rf = constrain(motor_rf, 1100, 2000);
  ...
} else {
  motor_rf = motor_rr = motor_lr = motor_lf = 1000;
  pidReset();   // avoid I-term windup at idle
}

Throttle is capped at 1800 to leave room for corrections.

Each motor stays between 1100 and 2000 while flying.

At idle throttle (≤ 1050) the motors stop and the PID memory is cleared.

Mixer and motors · 89 · Source: Esp32_drone.ino motorMix()

Why stop the motors at idle instead of idling at 1100? With the throttle stick fully down, the pilot expects props to stop, and a drone sitting on the ground must not fight the floor with I-term corrections. Once the throttle passes 1050, the 1100 floor keeps every prop turning in the air.
