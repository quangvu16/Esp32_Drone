usToDuty(): from 1000–2000 to 0–1023

inline uint16_t usToDuty(int16_t us) {
  if (us <= 1000) return 0;
  if (us >= 2000) return MOTOR_PWM_MAX;   // 1023
  return (uint16_t)(((uint32_t)(us - 1000)
                     * MOTOR_PWM_MAX) / 1000);
}

The code thinks in “µs” like a big-drone ESC, then converts at the last step.

Why keep 1000–2000? Familiar numbers, and the same mixer works if you ever swap to ESCs.

The uint32_t cast stops the multiply from overflowing 16 bits.

Example

1500 → (500 × 1023) ÷ 1000 = 511 → about 50% duty. 1100 → 102 → 10% duty, the armed minimum.

This is a straight line: 1000 maps to 0% duty and 2000 maps to 100%. The first two lines handle values outside the range, so the PWM register never gets an impossible number.
