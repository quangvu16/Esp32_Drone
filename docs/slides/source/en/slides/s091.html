Setting up the PWM hardware (LEDC)

for (uint8_t i = 0; i < 4; i++) {
  pinMode(pins[i], OUTPUT);
  digitalWrite(pins[i], LOW);
#if ESP_ARDUINO_VERSION_MAJOR >= 3
  ledcAttach(pins[i], MOTOR_PWM_FREQ_HZ, MOTOR_PWM_BITS);
#else
  ledcSetup(i, MOTOR_PWM_FREQ_HZ, MOTOR_PWM_BITS);
  ledcAttachPin(pins[i], i);
#endif
}

LEDC is the ESP32's PWM peripheral. It was made for LEDs, but drives MOSFETs just as well.

Two APIs: Arduino-ESP32 core 3.x changed the function names, so both are supported.

Pins are driven LOW first: motors off.

Why the #if? Version 3 of the Arduino-ESP32 core replaced ledcSetup and ledcAttachPin with a single ledcAttach that works by pin instead of by channel. Supporting both lets the sketch build on older and newer installs. Shortened: the real condition also checks that the version macro exists.
