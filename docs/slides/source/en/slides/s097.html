An SBUS frame: 25 bytes

An SBUS frame: 25 bytes, every 7–14 ms.

Byte 0: header 0x0F, the start of a frame.

Bytes 1–22: 16 channels × 11 bits, packed tight.

Byte 23: flags. Byte 24: footer (0x00, or 0x04/0x14/0x24/0x34 on SBUS2).

A frame arrives about every 7 to 14 ms depending on the receiver. sbusPoll() waits for the 0x0F header, collects 25 bytes, then checks the frame before decoding. The flags byte is the receiver telling us whether it can still hear the transmitter.
