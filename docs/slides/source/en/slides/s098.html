Radio inputs

Unpacking 11-bit channels

sbus_raw[0] = (b[1]      | b[2] << 8)             & 0x7FF;
sbus_raw[1] = (b[2] >> 3 | b[3] << 5)             & 0x7FF;
sbus_raw[2] = (b[3] >> 6 | b[4] << 2 | b[5] << 10) & 0x7FF;
...   // 13 more lines, same pattern

Channels do not line up with bytes: each is 11 bits, so they straddle byte edges.

Shift moves the bits into place; OR joins the pieces; & 0x7FF keeps 11 bits.

Values run 0–2047; a normal stick uses about 172–1811.

Example

b[1] = 0xE0, b[2] = 0x03 → (0xE0 | 0x03 << 8) & 0x7FF = 0x3E0 = 992, the stick centre.

Work one example: channel 0 is the low 8 bits from byte 1 plus the low 3 bits of byte 2. Channel 1 starts at bit 3 of byte 2. Each new channel starts 11 bits after the last, so the shift amounts repeat every 8 channels.
