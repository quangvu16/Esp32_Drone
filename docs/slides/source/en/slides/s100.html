while (Serial2.available()) {
  uint8_t c = Serial2.read();
  if (sbus_idx == 0 && c != 0x0F) continue;  // wait for header
  sbus_buf[sbus_idx++] = c;
  if (sbus_idx >= SBUS_FRAME_LEN) {
    sbus_idx = 0;
    if (sbusFrameUsable(sbus_buf)) sbusDecode(sbus_buf);
  }
}

Why never wait? sbusPoll() runs inside the 4 ms loop. If it blocked until a whole frame arrived, the control loop would stall for up to 14 ms. Instead it takes whatever bytes are ready and finishes the frame in a later loop. Shortened: the real code uses the SBUS_MIN and SBUS_MAX constants.
