CRTP: the phone's language

CRTP: the first byte says where the packet goes.

CRTP comes from the Crazyflie project; the ESP-Drone apps speak it.

The header's high 4 bits pick the port, the low 2 bits the channel.

crtpDispatch() reads the port and calls the right handler.

Example

port = (byte >> 4) & 0x0F; channel = byte & 0x03. For 0x71: port 7, channel 1.

Why reuse an existing protocol? The Android and iOS apps were built from Bitcraze's Crazyflie client libraries, so matching their byte layouts exactly means the apps work without changes. The comments in the sketch pin each layout to the Java class it comes from.
