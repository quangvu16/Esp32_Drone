The CRTP layer never knows which transport is active: it calls linkSend() and receives through crtpReceiveFramed() or crtpReceiveRaw(). That separation is why adding BLE did not touch any flight code. BLE is limited to 20 bytes per write, so a 30-byte CRTP packet is split into two segments with a control byte.
