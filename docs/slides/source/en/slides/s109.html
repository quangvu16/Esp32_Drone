Port 7: the flight-control commands

CodeCommandWhat it does
0x01SET_MODEMANUAL, HOLD, AUTO, FOLLOW, RTH (refused while battery critical)
0x02 / 0x03TAKEOFF / LANDstart the ramp up / the ramp down
0x04SET_HOVERhover thrust, clamped to 8000 – 55000
0x05EMERGENCYmotors off now — always honoured
0x07 / 0x08ARM / DISARMARM only from idle; DISARM always
0x09 – 0x0BSAVE / DEFAULTS / LOADsettings in flash; SAVE refused while armed
0x10LINKchange transport profile and reboot; refused while armed

Radio inputs · 109 · Source: Esp32_drone.ino crtpHandleFlightControl()

Every command replies with three bytes: 0x70, the command code, and a status (0 = OK, 1 = refused). The app resends every 500 ms until it sees that reply, which is why each command must be safe to apply twice. Channel 1 (0x71) carries navigation: TARGET, RESET and ALIGN, covered in section 10.
