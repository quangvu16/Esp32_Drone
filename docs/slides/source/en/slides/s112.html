Modes and safety

Five flight modes

ModeWho fliesWhat the drone holds
MANUALpilot (phone sticks or RC)nothing automatic — sticks command tilt or rate
HOLDdronelevel attitude, locked heading, a fixed thrust
AUTOdronetake-off ramp → hover → landing ramp
FOLLOWdrone + phone GPStilts toward the phone's target offset
RTHdronetilts back toward the launch point

Modes apply to the phone path only. SBUS always flies MANUAL.

Modes and safety · 112 · Source: Esp32_drone.ino FLIGHT MODES section comment

None of these modes holds altitude: there is no barometer, so HOLD keeps a thrust level and the height drifts with the battery. SBUS always stays in manual rate mode, because the physical RC is the safety net and must never be overridden by an automatic mode.
