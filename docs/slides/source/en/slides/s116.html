Arming from the phone: three rules

Thrust low first

In MANUAL, thrust-up arms only after the app has shown thrust at zero. A phone that connects with the stick up cannot spin the props.

ARM only from idle

ARM is refused in HOLD, FOLLOW or RTH, where motors would jump to hover thrust. Use TAKEOFF there.

TAKEOFF arms safely

It checks the battery, sets the launch point and starts the ramp from zero.

Modes and safety · 116 · Source: Esp32_drone.ino armUpdate(), FC_CMD_ARM, flightTakeoff()

Each rule prevents a real accident: the first stops a surprise full-throttle start on reconnect; the second stops a jump to hover thrust on the bench; the third makes sure the only way into automatic flight starts from zero thrust. A reconnect also clears crtp_thrust_was_low, so it must see zero again.
