One pre-arm check for every path

bool armChecksOk(const char *who) {
#if VBAT_ARM_CHECK
  if (vbat < VBAT_CELLS * VBAT_CELL_CRIT) {      // 3.3 V
    // rate-limited message, at most once a second
    Serial.printf("[ARM] %s refused: battery %.2f V\n", who, vbat);
    crtpConsole("arm refused: low battery");
    return false;
  }
#endif
  return true;
}

Called by SBUS arming, CRTP thrust-up, ARM and TAKEOFF.

Why one function? A new check added here protects every path at once.

The message is rate-limited so a held stick cannot flood the console.

Modes and safety · 117 · Source: Esp32_drone.ino armChecksOk()

Before this function existed, each arming path had its own checks, and they drifted apart. Putting the rule in one place is a classic safety pattern. The who argument says which path asked, which helps when reading the serial log. Shortened from the sketch.
