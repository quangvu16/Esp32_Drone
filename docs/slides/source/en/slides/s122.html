Critical battery → the drone lands itself

if (armed && vbat_crit) {
  if (use_crtp && flight_mode != MODE_MANUAL) {
    if (!(flight_mode == MODE_AUTO && auto_state == AUTO_LAND))
      flightLand();                     // land once
  } else {
    // RC or MANUAL pilot: warn every 2 s, do not take over
    crtpConsole("battery critical: land now");
  }
}
// and SET_MODE is refused while armed && vbat_crit

Automatic modes land; a human pilot gets a warning.

SET_MODE is refused so the app's regular mode resend cannot cancel the landing.

Modes and safety · 122 · Source: Esp32_drone.ino loop(), FC_CMD_SET_MODE

Why not take control from a manual pilot? A pilot may be over water or trees and need a few seconds to fly to a safe spot; forcing a landing could be worse. In automatic modes nobody is flying, so the drone lands. Shortened from loop() and the SET_MODE handler.
