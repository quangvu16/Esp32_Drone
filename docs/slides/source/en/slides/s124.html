Modes and safety

Things that are refused while armed

SAVE

Flash erase stalls both CPU cores for milliseconds — a missed control loop.

LINK

Writes flash and reboots. A reboot in the air is a crash.

Serial link / sta / save

The bench console has the same rule: “refused while armed — disarm first”.

Example

Tap Save in the Tune screen while hovering → reply status 1 → the app shows that the save was refused.

The pattern: anything that can pause the CPU or restart the chip is only allowed on the ground. The phone app greys out these buttons while armed, but the firmware enforces the rule anyway, because the firmware is the last line of defence.
