Removing gravity

const float ax_b = raw_ax / NAV_ACC_LSB_PER_G * G;   // m/s²
const float ay_b = raw_ay / NAV_ACC_LSB_PER_G * G;
// gravity seen by the tilted sensor
const float gx_g = -G * sin(roll) * cos(pitch);
const float gy_g = +G * sin(pitch);
float fwd  = (ay_b - gy_g) * NAV_FWD_SIGN;
float left = (ax_b - gx_g) * NAV_LEFT_SIGN;

A tilted drone feels part of gravity on its flat axes, even when it is not moving.

The tilt angles from section 5 say how much; subtract it.

What is left is real horizontal acceleration.

Example

Tilted 5° forward, not moving: ay_b ≈ 9.81 × sin 5° = 0.85 m/s². Subtract gy_g = 0.85 → fwd = 0.
