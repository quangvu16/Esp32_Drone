The leaky integrator

The leaky integrator forgets old velocity.

Each second, velocity keeps only 60% of itself: a bias cannot build up forever.

powf(0.60, dt) makes that true per second whatever the loop rate (≈ 0.998 per loop).

When holding, velocity is set to zero — the one thing the drone knows for certain.

Why powf(0.60, dt)? It makes the leak correct per second whatever the loop rate: at 4 ms, each loop multiplies by about 0.998. The comment calls this the right trade for a craft that mostly hovers. The holding reset is the strongest fix, because it uses something the drone knows for certain.
