run.sh guards: the tests cannot go stale

check() {
  if ! grep -qF "$1" "$sketch"; then
    echo "STALE TEST: '$1' is no longer in Esp32_drone.ino"
    exit 1
  fi
}
check 'roll_setpoint  = sp_roll_rate  - roll_level_adjust;'
check 'if (f[23] & 0x08) return false;'
check 'tgt_y = n * sa - e * ca;'

The tests copy formulas from the sketch, because the sketch cannot be compiled on a PC.

A copy could quietly go out of date. check fails loudly if the exact line has changed.

Extra guards: mode bounds, accelerometer scale, NAV_HEADING_SIGN.

Testing · 141 · Source: Esp32_drone/test/run.sh

Why not compile the real sketch for the PC? It depends on Arduino, Wi-Fi and Bluetooth libraries. Copying a few pure-maths lines is much simpler, and the guard makes the copy trustworthy: if you change a guarded line, run.sh tells you to update the test first.
