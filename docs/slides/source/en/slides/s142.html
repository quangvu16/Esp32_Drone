Inside level_test: a tiny simulation

static float simulate(float angle0, float sp_deg,
                      float sign, float seconds) {
  float angle = angle0;
  for (int i = 0; i < (int)(seconds / 0.004f); i++) {
    float err = angle - sp_deg;
    float adj = clampf(err * 15.0f, -200, 200);
    float gyro = 0.0f + sign * adj;  // perfect rate loop
    angle += gyro * 0.004f;
    if (fabsf(angle) > 180.0f) return angle;   // flipped
  }
  return angle;
}

Models one axis at 250 Hz with a perfect rate loop.

sign −1 = today's firmware → the angle shrinks to the target.

sign +1 = the old bug → the angle grows and flips.

Example

Start at +10°, target 0°: after 1 s with sign −1 → about 0°. With sign +1 → past 180°, flipped.
