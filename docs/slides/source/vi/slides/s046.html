loop() trong mười hai dòng

sbusPoll();  linkPoll();            // 1. receive
// 2. decide who is in control, failsafe
if (!rx_ok && armed) { armed = false; motorStop(); }
armUpdate(now, use_crtp);           // 3. arm / disarm
mpuReadRaw();  attitudeUpdate();    // 4. sense
navUpdate(...);                     // 5. dead reckoning
flightSetpoints(now, use_crtp, sbus_ok);  // 6. want
roll_setpoint = sp_roll_rate - roll_level_adjust;
pidCompute();                       // 7. decide
motorMix(sp_throttle_us);           // 8. mix
motorWrite(motor_rf, motor_rr, motor_lr, motor_lf);
batteryUpdate(); logUpdate(); telemetry(now);
while (micros() - loop_timer < LOOP_TIME_US) { }

Đã rút gọn — loop thật có chú thích và các kiểm tra giữa các dòng.

Thứ tự quan trọng: kiểm tra an toàn chạy trước cảm biến và điều khiển, nên mất kết nối sẽ dừng động cơ ngay trong vòng đó.

Hãy đọc slide này hai lần. Mọi phần sau đều phóng to vào một dòng ở đây. Kỹ năng hữu ích nhất với mã này là nói được, với mỗi biến, bước đánh số nào thay đổi nó. (1 nhận, 2 quyết định ai điều khiển, 3 arm, 4 cảm nhận, 5 ước tính vị trí, 6 điều muốn, 7 quyết định, 8 trộn.)
