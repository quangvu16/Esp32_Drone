Bộ trộn và động cơ

Bộ trộn: bốn dòng

motor_rf = t - pitch + roll - yaw * YAW_DIRECTION;
motor_rr = t + pitch + roll + yaw * YAW_DIRECTION;
motor_lr = t + pitch - roll - yaw * YAW_DIRECTION;
motor_lf = t - pitch - roll + yaw * YAW_DIRECTION;

t = ga, như nhau cho cả bốn.

Roll: + ở cặp phải, − ở cặp trái.

Pitch: + ở cặp sau, − ở cặp trước.

Yaw: + ở một đường chéo (RR, LF), − ở đường chéo kia (RF, LR).

Ví dụ

Dấu mỗi cột cộng lại bằng 0: roll + + − − = 0, pitch − + + − = 0, yaw − + − + = 0.
