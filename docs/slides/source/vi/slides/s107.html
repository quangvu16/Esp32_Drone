Tham số: TOC và kiểm tra dải

{ "pid", "roll_kp", PT_FLOAT, 4, TOC_ACCESS_RW,
  &pid_p_gain_roll, 0.0f, 100.0f },
{ "flight", "takeoff_ms", PT_UINT16, 2, TOC_ACCESS_RW,
  &takeoff_ms, 100.0f, 20000.0f },
// on write:
if (!isfinite(v)) return;    // refused
v = paramClampF(e, v);       // clamp into [lo, hi]

TOC = mục lục: ứng dụng tải danh sách tên, kiểu và quyền truy cập.

Mỗi mục đọc-ghi mang dải lo và hi.

Phản hồi lặp lại giá trị thật đã lưu, nên ứng dụng hiện đúng sự thật.

Ví dụ

Ứng dụng ghi roll_kp = 1000 → lưu thành 100 (giới hạn hi) → phản hồi báo ứng dụng 100.

Đầu vào · 107 · Nguồn: PARAM_TOC, paramStore()

Vì sao kiểm tra? Trước bản sửa này, hệ số NaN hoặc takeoff_ms bằng 0 từ ứng dụng lọt vào mã bay. takeoff_ms là số chia trong đường dốc cất cánh, nên 0 nghĩa là chia cho 0. Giờ mọi lần ghi đều được kiểm tra, và giá trị nạp từ flash cũng vậy (paramSanitizeAll).
