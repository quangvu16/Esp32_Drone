Chế độ và an toàn

Pin nguy hiểm → drone tự hạ cánh

if (armed && vbat_crit) {
  if (use_crtp && flight_mode != MODE_MANUAL) {
    if (!(flight_mode == MODE_AUTO && auto_state == AUTO_LAND))
      flightLand();                     // land once
  } else {
    // RC or MANUAL pilot: warn every 2 s, do not take over
    crtpConsole("battery critical: land now");
  }
}
// and SET_MODE is refused while armed && vbat_crit

Chế độ tự động thì hạ cánh; phi công người thì nhận cảnh báo.

SET_MODE bị từ chối để việc ứng dụng gửi lại chế độ định kỳ không hủy việc hạ cánh.

Vì sao không giành quyền của phi công thủ công? Phi công có thể đang ở trên mặt nước hay cây cối và cần vài giây bay tới chỗ an toàn; ép hạ cánh có thể tệ hơn. Ở chế độ tự động không ai lái, nên drone hạ cánh. Rút gọn từ loop() và handler SET_MODE.
