Bỏ trọng lực

const float ax_b = raw_ax / NAV_ACC_LSB_PER_G * G;   // m/s²
const float ay_b = raw_ay / NAV_ACC_LSB_PER_G * G;
// gravity seen by the tilted sensor
const float gx_g = -G * sin(roll) * cos(pitch);
const float gy_g = +G * sin(pitch);
float fwd  = (ay_b - gy_g) * NAV_FWD_SIGN;
float left = (ax_b - gx_g) * NAV_LEFT_SIGN;

Drone nghiêng cảm nhận một phần trọng lực trên các trục ngang, kể cả khi đứng yên.

Góc nghiêng từ phần 5 cho biết bao nhiêu; trừ nó đi.

Phần còn lại là gia tốc ngang thật.

Ví dụ

Chúc 5° về trước, không di chuyển: ay_b ≈ 9,81 × sin 5° = 0,85 m/s². Trừ gy_g = 0,85 → fwd = 0.
