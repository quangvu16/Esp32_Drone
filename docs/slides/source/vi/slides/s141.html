Các kiểm tra trong run.sh: bài kiểm thử không thể lỗi thời

check() {
  if ! grep -qF "$1" "$sketch"; then
    echo "STALE TEST: '$1' is no longer in Esp32_drone.ino"
    exit 1
  fi
}
check 'roll_setpoint  = sp_roll_rate  - roll_level_adjust;'
check 'if (f[23] & 0x08) return false;'
check 'tgt_y = n * sa - e * ca;'

Bài kiểm thử chép công thức từ sketch, vì sketch không biên dịch được trên máy tính.

Bản chép có thể lỗi thời âm thầm. check báo lỗi to nếu đúng dòng đó bị đổi.

Vì sao không biên dịch sketch thật cho máy tính? Nó phụ thuộc thư viện Arduino, Wi-Fi và Bluetooth. Chép vài dòng toán thuần đơn giản hơn nhiều, và kiểm tra này làm bản chép đáng tin: nếu bạn đổi một dòng được canh, run.sh bảo bạn cập nhật bài kiểm thử trước.
