Bên trong level_test: một mô phỏng nhỏ

static float simulate(float angle0, float sp_deg,
                      float sign, float seconds) {
  float angle = angle0;
  for (int i = 0; i < (int)(seconds / 0.004f); i++) {
    float err = angle - sp_deg;
    float adj = clampf(err * 15.0f, -200, 200);
    float gyro = 0.0f + sign * adj;  // perfect rate loop
    angle += gyro * 0.004f;
    if (fabsf(angle) > 180.0f) return angle;   // flipped
  }
  return angle;
}

Mô phỏng một trục ở 250 Hz với vòng tốc độ hoàn hảo.

sign −1 = firmware hiện tại → góc co về mục tiêu.

sign +1 = lỗi cũ → góc tăng và lật.

Ví dụ

Bắt đầu ở +10°, mục tiêu 0°: sau 1 s với sign −1 → khoảng 0°. Với sign +1 → vượt 180°, lật.
